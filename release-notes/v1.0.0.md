## What's new

- **Google Cardboard VR on Android** - play Virtual Boy games in full color
  and stereoscopic 3D in a Cardboard-compatible phone viewer. A clean phone
  install starts in Cardboard mode while existing display choices are
  preserved. Scan the viewer's QR code for calibrated lens correction;
  custom viewer profiles are supported. The view stays fixed in front of
  you, with no head tracking.
- **A comfortable adjustable screen** - Cardboard mode starts at 80% size;
  adjust it from 50% to 125% in Settings → Screen → Cardboard screen size.
- **A usable in-view menu** - open it with Select + Start or Guide; Android
  Back exits Cardboard mode and returns to ordinary phone display.

The Android APK supports 64-bit Android phones and Meta Quest. No games are
included. Use ROMs made from cartridges you own.
